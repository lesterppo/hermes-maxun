# hermes-maxun — Maxun web-extraction tool for Hermes Agent

An AI-agent-native `maxun` tool that wraps the [Maxun](https://github.com/getmaxun/maxun)
open-source web-data-extraction platform, plus its skill and reliability audit.

Turn a website into structured data from a single plain-English prompt — no
code, no selectors. The tool drives a self-hosted or cloud Maxun instance over
its REST API and returns compact JSON (full data offloaded to a file so the
agent's context stays small).

## What it does

Nine actions, one tool, minimal schema footprint:

| action | purpose |
|--------|---------|
| `list_robots` | list existing extraction robots |
| `get_robot` | inspect a robot |
| `create_ai_robot` | **build a robot from a natural-language prompt** (the headline action) |
| `create_search` | build a web-search robot from a query |
| `run` | execute a robot, capture structured data (`wait=false` for non-blocking) |
| `list_runs` | run history for a robot |
| `get_run` | one run's full data (saved to a file) |
| `abort_run` | cancel a running/queued run |
| `duplicate` | clone a robot onto a new URL |

Full schema, parameters, and pitfalls: `skills/maxun-tool/SKILL.md`.

## Install

```bash
git clone https://github.com/lesterppo/hermes-maxun.git
cd hermes-maxun
./install.sh /path/to/your/hermes-agent   # copies tool + skill idempotently
```

`install.sh` copies the tool into `tools/` and the skill into
`~/.hermes/skills/maxun-tool/`, then verifies the tool imports. It does **not**
edit core files automatically (see "Wire into a toolset" below).

## Wire into a toolset (required for the model to see it)

The tool self-registers via the registry import, but Hermes only exposes a
tool to the model when it is listed in a toolset. Add `"maxun"` to one of:

- `_HERMES_CORE_TOOLS` (the shared list every platform inherits from) — easiest,
  propagates to CLI/TUI/gateway/Telegram/Discord:
  ```python
  _HERMES_CORE_TOOLS = [
      # Web
      "web_search", "web_extract", "maxun",
      ...
  ]
  ```
- or the `"web"` toolset dict:
  ```python
  "web": {
      "description": "Web research and content extraction tools",
      "tools": ["web_search", "web_extract", "maxun"],
      "includes": [],
  },
  ```

Optionally add the env vars to `hermes_cli/config.py` so `hermes setup` /
`/secret` discover them (see `skills/maxun-tool/references/maxun-selfhost-recipe.md`
for the exact `OPTIONAL_ENV_VARS` block).

## Configure

```bash
hermes setup          # then add MAXUN_API_KEY + MAXUN_API_URL
# or /secret in a running session
```

- `MAXUN_API_URL` — default `http://localhost:8080` (self-hosted) or
  `https://app.maxun.dev/api` (cloud).
- `MAXUN_API_KEY` — generate in the Maxun dashboard (register a user, then
  *API Key* tab, or `POST /auth/generate-api-key`).

The tool is **gated** by `check_fn`: it only appears in the model's schema when
both env vars are set — zero footprint otherwise.

## Self-host Maxun

See `skills/maxun-tool/references/maxun-selfhost-recipe.md` for the docker-compose
`.env` essentials (notably `BROWSER_WS_HOST=browser`, required for the AI robot
builder's browser). A working `docker-compose.yml` ships with Maxun; enable the
local `build:` stanza to apply the API-key abort patch below.

## Optional: API-key abort patch

Upstream Maxun gates the abort endpoint behind a session cookie, so the `abort_run`
action could not reach it. `patches/maxun-abort-apikey.patch` adds an API-key
variant of the abort route (`/storage/runs/abort/:id`) registered before the
session-guarded one. Apply it to your Maxun clone and rebuild the backend image:

```bash
cd /path/to/maxun
git apply /path/to/hermes-maxun/patches/maxun-abort-apikey.patch
# enable the `build:` stanza in docker-compose.yml, then:
docker compose build backend && docker compose up -d --force-recreate backend
```

Without the patch, `abort_run` returns a clear hint that abort is session-gated.

## Reliability audit

```bash
python3 /path/to/hermes-agent/tools/maxun_tool_audit.py
# set MAXUN_API_KEY + MAXUN_API_URL to also exercise live-call paths
```

Targets load, input validation, token cost (compact JSON), accuracy, edge
cases, and integration. Aims for 100% pass.

## Privacy

This repository contains **no secrets, API keys, or personal paths**. The
Maxun API key is generated by each user in their own instance. All paths use
`~/.hermes` / `get_hermes_home()` so it is profile-aware and safe to share.
